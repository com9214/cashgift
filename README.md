# 경조사비 기록장

결혼식·장례식 등에서 주고받은 경조사비를 별칭으로 기록하고 살펴보는 단일 HTML 웹앱입니다. 설치나 서버 없이 브라우저에서 사용할 수 있습니다.

## 사용하기

- `index.html`을 내려받아 더블 클릭하면 브라우저에서 열립니다.
- 기록은 해당 브라우저의 기기에만 저장됩니다. 서버로 전송되거나 기기 사이에 자동 동기화되지 않습니다.
- 브라우저의 사이트 데이터를 지우면 기록이 사라질 수 있으니 CSV로 따로 보관하세요.
- 온라인 공개본을 사용할 때도 실제 기록은 방문한 사람의 브라우저 안에 저장됩니다.

## 포함된 파일

- `index.html` — 경조사비 기록 웹앱
- `경조사비 기록장 사용설명서.docx` — A4 사용설명서
- `경조사비 기록장 사용설명서.html` — 브라우저용 사용설명서

웹앱은 별칭 검색, 연도·관계 필터, 사람별 받은 금액·보낸 금액과 차액, 연도별·종류별 합계, CSV 가져오기·내보내기 기능을 제공합니다.
